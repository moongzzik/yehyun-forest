    📋 학습 리포트

    📲 홈 화면에 추가

    설치용 주소: https://moongzzik.github.io/yehyun-forest/
    이 주소를 크롬·사파리에서 열어야 '앱 설치'가 돼요.

    ⚠️ 카카오톡 안에서 열었다면 먼저 오른쪽 위 ⋮ / ⋯ → 다른 브라우저로 열기를 눌러 주세요. 카카오톡 안에서는 설치가 안 돼요.

    아이폰 (Safari)

    1. 이 페이지를 Safari로 열어요 (Claude 앱 안이라면 공유 → 'Safari로 열기')
    2. 화면 아래 가운데 공유 버튼 (□↑)을 눌러요
    3. 아래로 내려 '홈 화면에 추가'를 눌러요
    4. 이름을 '예현이의 숲'으로 하고 추가!

    🤖 안드로이드 (Chrome)

    1. 이 페이지를 Chrome으로 열어요
    2. 오른쪽 위 ⋮ 메뉴를 눌러요
    3. '홈 화면에 추가' (또는 '앱 설치')를 눌러요
    4. 추가를 누르면 끝!

    💡 설치한 앱의 기록은 그 휴대폰에 저장돼요. 휴대폰을 바꿀 땐 ⚙️ 설정 → 백업 코드로 옮겨 주세요.
